# glft's engine isn't answering

## What happened
glft's background engine is running but didn't answer within 2 seconds.

## Why
It is stuck or very busy. glft says so rather than waiting without end.

## What to do
In a terminal, run `glft restart`. An open window reconnects by itself, and unfinished
transfers continue after the restart.

## If you ask for help
Include the log: "Share as text" on the phone, "Copy all" in the window, or `glft log` in
a terminal. It shows each step and the details of the error, and holds no file contents.
