# Local network access is off

## What happened
glft can't reach devices on your local network.

## Why
Android can deny an app access to the local network, and it is denied for glft.

## What to do
- **On the phone:** Settings, Apps, glft, Permissions: allow local network access
  (shown as **Nearby devices** on some versions).
- **On a computer:** check that no firewall blocks glft on the local network.
