# A file couldn't be read

## What happened
glft couldn't read one of the files you chose to send.

## Why
It was moved, deleted or renamed after you chose it, it belongs to another user, or, on
the phone, the app that shared it no longer allows reading it.

## What to do
- Check that the file still exists and opens.
- On the phone, share it again from the app it's in, or choose it again in glft.
- The details say which file it was.
