# The send didn't start

## What happened
The send was chosen but never began.

## Why
Android refused to start glft's transfer job, or glft was restarted before the job ran
and the choice of files was lost.

## What to do
Send the files again. If it keeps happening, restart the phone.

## If you ask for help
Include the log: "Share as text" on the phone, "Copy all" in the window, or `glft log` in
a terminal. It shows each step and the details of the error, and holds no file contents.
