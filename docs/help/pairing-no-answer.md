# The device showing the code didn't answer

## What happened
The code was scanned, but the device that showed it couldn't be reached.

## Why
The two devices aren't on the same network, the code was closed, or it ran out: codes work
once, for 5 minutes.

## What to do
- Check that both devices are on the same Wi-Fi.
- Start pairing again on the computer (**Pair a phone…**, or `glft pair`) and scan the
  new code.

## If you ask for help
Include the log: "Share as text" on the phone, "Copy all" in the window, or `glft log` in
a terminal. It shows each step and the details of the error, and holds no file contents.
