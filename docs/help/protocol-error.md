# Something unexpected arrived

## What happened
The other device sent something glft didn't expect at that point.

## Why
Usually the two devices run different versions of glft; rarely, a damaged connection.

## What to do
Update glft on both devices to the same version, then send again.

## If you ask for help
Include the log: "Share as text" on the phone, "Copy all" in the window, or `glft log` in
a terminal. It shows each step and the details of the error, and holds no file contents.
