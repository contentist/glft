# Not a valid device id

## What happened
The device id given isn't a glft id. A full id is 64 letters and digits; the short form
`glft devices` shows is its first 10.

## Why
It was mistyped or only partly copied.

## What to do
- **In a terminal:** use the device's name as `glft devices` lists it, or copy the full id
  again.
- **In the window or on the phone:** pair the device again.
